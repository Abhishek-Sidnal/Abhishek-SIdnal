## 👋 About me

I build web products end to end: the database, the API, the screens and the deploy. Lately that means multi-tenant SaaS on **Node.js, React, Angular and Azure**, real-time features over Socket.IO, and AI document pipelines that keep personal data out of the model.

<br />

<table>
  <tr>
    <td width="50%" valign="top">

      Tenant isolation, role-based access, per-tenant cloud resources and custom domains.
    </td>
    <td width="50%" valign="top">
      <h3>🔔 Real-time apps</h3>

    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">

    </td>
    <td width="50%" valign="top">
      <h3>🤖 AI with privacy</h3>
      Document extraction pipelines that mask personal data before it reaches an AI model.
    </td>
  </tr>
